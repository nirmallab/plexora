                           [--table TABLE] [--subset COLUMN=VALUE] [--cell-id CELL_ID] [--x X]
                           [--y Y] [--sample SAMPLE] [--celltype CELLTYPE]

## Examples

**Say which columns are markers**

```bash
plexora project set slide --markers CD3 CD8 CD20
```

**Add a cell table later**

```bash
plexora project set slide --data cells.csv
```

**Move the project into a dataset**

```bash
plexora project set slide --dataset "Melanoma cohort"
```

## Python equivalent

```python
import plexora

plexora.configure_project("slide", markers=["CD3", "CD8", "CD20"])
```
