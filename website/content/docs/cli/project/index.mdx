## Usage

```bash
plexora project [-h] {create,show,set} ...
```

An image is the only thing a project must have. Everything else can be added later, and Plexora asks for what it needs when something needs it.

## Examples

**Register an image with its mask and cell table**

```bash
plexora project create slide.ome.tif --segmentation slide_mask.tif --data cells.csv
```

**Import a Xenium output folder**

```bash
plexora project create /data/xenium/output-XETG00001
```
