Register a project without opening the viewer. Give one image and name
the other files with options, or give several paths (or a run folder)
and let Plexora work out what each one is. Anything you leave out can
be added later with `plexora project set`, and Plexora asks for what a
tool needs when it needs it.

## Usage

```bash
plexora project create [-h] [--name NAME] [--segmentation SEGMENTATION] [--data DATA]
                              [--table TABLE] [--subset COLUMN=VALUE] [--cell-id CELL_ID] [--x X]
                              [--y Y] [--sample SAMPLE] [--celltype CELLTYPE]
                              [--markers COLUMN [COLUMN ...]] [--metadata COLUMN [COLUMN ...]]
                              [--layer LAYER] [--log1p] [--single-image] [--row-number-ids]
                              [--channel-names NAME [NAME ...]]
                              [--image-type {brightfield,fluorescence}] [--copy] [--node NAME]
                              [--dataset DATASET] [--from SPEC.json] [--exist-ok] [--json]
                              PATH [PATH ...]
```

## Examples

**An image is enough**

```bash
plexora project create slide.ome.tif
```

**Name every file**

```bash
plexora project create slide.ome.tif --segmentation slide_mask.tif --data cells.csv --x X_centroid --y Y_centroid --cell-id CellID
```

**Let Plexora work out what each file is**

```bash
plexora project create slide.ome.tif slide_mask.tif cells.csv
```

**A run folder, into a dataset**

```bash
plexora project create /data/visium_hd/outs --dataset "Pancreas"
```

**A table covering several images**

```bash
plexora project create slide1.ome.tif --data all_cells.csv --subset imageid=slide1
```

## Python equivalent

[`plexora.create_project`](/docs/python-api/projects/create-project) takes the same options by the same names
(dashes become underscores). [`plexora.import_sample`](/docs/python-api/projects/import-sample) is the
several-paths form.

```python
import plexora

plexora.create_project(
    "slide.ome.tif",
    segmentation="slide_mask.tif",
    data="cells.csv",
    x="X_centroid",
    y="Y_centroid",
    cell_id="CellID",
)
```
