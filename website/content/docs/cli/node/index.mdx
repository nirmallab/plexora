## Examples

**Serve an image and a table from this machine**

```bash
plexora node serve --serve image:tonsil=/data/tonsil.ome.tif --serve table:cells=/data/cells.csv
```

**Start a node on a cluster and register it here**

```bash
plexora node connect me@hpc.example.edu --serve image:tonsil=/scratch/me/tonsil.ome.tif
```
