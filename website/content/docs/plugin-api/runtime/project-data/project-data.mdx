Also available as `plexora.api.dataset`.

```python
project_data(name: str) -> ProjectData
```

Construction is cheap: it reads the project record only. Nothing is
loaded from disk until a handle method is actually called.

## How is this different?

<Compare title={"project_data or dataset?"}>

`plexora.api.dataset` is the same function under its older name. A
dataset in Plexora is now a folder of projects ([`plexora.create_dataset`](/docs/python-api/datasets/create-dataset)),
so plugin code should call `project_data`.
