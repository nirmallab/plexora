Called `Dataset` until a Dataset became the folder a cohort of projects
lives in ([`plexora.create_dataset`](/docs/python-api/datasets/create-dataset)) -- two things one word could not be,
and this was the one that was always misnamed: it is not a dataset, it is
the data of one project. `Dataset` stays as an alias for a plugin already
using the old name.

## Methods

### not_called

```python
not_called(markers=())
```

Rows QC says cannot be called for any of `markers` -- a cell inside a QC region, or one QC flagged that marker unreliable in -- under the current call mode (`plexora.agent.cell_exclusions`).

<ParamTable>

<Param name={"markers"} type={"list"} default={"()"}>

Marker columns; empty means the cells
not called for every marker.

</Param>

</ParamTable>

<Returns>

A boolean numpy array, one entry per row of `table.geometry()`,
True where the cell is not called; None when every row is called
(no QC, or nothing failed).

</Returns>

### calls

```python
calls(gates: Mapping[str, tuple], mode: str = 'and')
```

A gate's call per row, with QC's third state.

<ParamTable>

<Param name={"gates"} type={"dict"} required>

`{column: (low, high)}` ranges.

</Param>

<Param name={"mode"} type={"str"} default={"'and'"}>

</ParamTable>

<Returns>

An int8 numpy array, one entry per row: 1 positive, 0 negative,
