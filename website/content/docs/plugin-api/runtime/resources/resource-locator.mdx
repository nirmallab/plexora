`path` is the honest answer only for a local resource. For a node-backed
one it is None: a plugin holding a path to a file on another machine
would open it, find nothing, and report a missing project. Code that used
to reach for `.path` should ask a [`plexora.api.ImageHandle`](/docs/plugin-api/runtime/project-data/image-handle),
[`plexora.api.SegHandle`](/docs/plugin-api/runtime/project-data/seg-handle) or [`plexora.api.TableHandle`](/docs/plugin-api/runtime/project-data/table-handle) to do the work
instead.
