Call `plexora.view(...)` and make it the last expression of a cell, and the
viewer appears inline, underneath the cell, next to the rest of your
analysis.

```python
import plexora

plexora.view("tonsil")
```

## What that call does

The first time a cell like this runs, Plexora starts a small server beside
your kernel — a *sidecar* — and shows it in an iframe in the cell's output.
A second `plexora.view(...)` in the same notebook, against the same data
directory, reuses that sidecar instead of starting another one, so opening
the same project from several cells costs nothing extra.

Naming a project that already exists opens it, exactly as typing its name
into the standalone application would. Passing data as well —
`plexora.view("tonsil", image="slide.ome.tif", adata=adata)` — registers it
first. See [In-memory data](/docs/notebooks/in-memory-data) for what each
argument can be.
