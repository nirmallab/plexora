title: "The desktop app"
description: "Install Plexora as a native app, and find where it keeps its data."
---

The desktop app is Plexora as an ordinary application — a native window, menus, file dialogs and drag-and-drop — around the same server the terminal command runs. Nothing about projects, plugins or remote connections differs from a pip install; what differs is who starts the server and who stops it, and that it needs no Python and no terminal.


## Install it

Download the installer for your system from the [releases page](https://github.com/nirmallab/plexora/releases).

<PlatformTabs>

<Tab value="macOS">

`Plexora-<version>-macos-arm64.dmg`, for a Mac with Apple silicon. Open the disk image and drag Plexora into Applications.

</Tab>

<Tab value="Windows">

`Plexora-<version>-windows-x64-setup.exe`. Run it; it installs for your account only.

</Tab>

<Tab value="Linux">

`Plexora-<version>-linux-x64.deb`, for Debian and Ubuntu.

</Tab>

</PlatformTabs>

## Where things are

<PlatformTabs>

<Tab value="macOS">

| | Location |
|---|---|
| Projects | the same data directory a terminal `plexora` uses |
| Logs | `~/Library/Logs/org.nirmallab.plexora` |
| The app | `/Applications/Plexora.app` |

</Tab>

<Tab value="Windows">

| | Location |
|---|---|
| Projects | the same data directory a terminal `plexora` uses |
| Logs | `%LOCALAPPDATA%\org.nirmallab.plexora\logs` |
| The app | `%LOCALAPPDATA%\Plexora` |

</Tab>

<Tab value="Linux">

| | Location |
|---|---|
| Projects | the same data directory a terminal `plexora` uses |
| Logs | `~/.local/share/org.nirmallab.plexora/logs` |
| The app | `/usr/lib/Plexora` |

</Tab>

</PlatformTabs>

Projects are never split between the app and a terminal install: both resolve the same data directory, so a sample imported in one shows up in the other. See [Data locations](/docs/data/data-locations) for how that directory is chosen. **Help → Show Data Folder** and **Help → Show Logs** open these directly from the app.

## Opening files from outside the app

- **Drag and drop** a slide, a run folder, or a table onto the window: the app hands its path to the Import dialog, or adds it to the project that is already open. Nothing is uploaded, so there is no size limit.
- **Open with Plexora**, from Explorer, Finder or a file manager: `.svs`, `.ndpi`, `.scn`, `.mrxs`, `.qptiff` and `.h5ad` are associated with Plexora as a viewer. `.tif` is deliberately not associated, since every TIFF on the machine would otherwise claim it.
- **A second launch** hands its files to the app that is already running and exits, so only one app and one server are ever open at once.

**File → Open in Browser** shows the same session in your web browser, if you would rather have it in a tab.

## Updates

Choose **Check for Updates…** from the **Help** menu (on macOS, it is under the **Plexora** menu instead) to check for a newer release.
