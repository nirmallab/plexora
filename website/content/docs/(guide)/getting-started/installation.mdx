The desktop app needs no Python and no terminal. Pick the installer for your computer. On a Linux system other than Debian or Ubuntu, a server or a cluster, [install with pip](/docs/getting-started/install-python) instead. Intel Macs are not supported.

<Downloads />

## How to use it

<Steps>
<Step>
### Run the installer

**macOS:** open the `.dmg` and drag Plexora into Applications. **Windows:** run the `.exe`; it installs for your account only, so it needs no administrator rights ([step by step, with screenshots](/docs/getting-started/install-windows)). **Linux:** `sudo apt install ./Plexora-<version>-linux-x64.deb`.
</Step>
<Step>
### Open Plexora the first time

The installers are not code-signed yet, so your system asks once before it opens the app. See [First launch](#first-launch) below.
</Step>
<Step>
### Open an image

Plexora opens on its home screen. Continue with [Your first image](/docs/getting-started/first-image).
</Step>
</Steps>

## First launch

<PlatformTabs>
<Tab value="macOS">
macOS says Plexora cannot be opened because Apple cannot check it. Open **System Settings › Privacy & Security**, scroll down and choose **Open Anyway** (on macOS 14 and earlier you can instead Control-click the app and choose **Open**). Or run once:

```bash
xattr -dr com.apple.quarantine /Applications/Plexora.app
```
</Tab>
<Tab value="Windows">
SmartScreen warns about an unrecognised publisher. Choose **More info**, then **Run anyway**. [Install on Windows](/docs/getting-started/install-windows) shows each screen.
</Tab>
<Tab value="Linux">
If the window opens blank, this computer's web engine cannot draw with WebGL 2, which the viewer needs, and Plexora says so. Choose **File › Open in Browser** to use the same session in your web browser.
</Tab>
</PlatformTabs>

## Tips

- The desktop app and a [pip install](/docs/getting-started/install-python) on the same computer share their projects: a sample imported in one appears in the other.
- **Help › Check for Updates…** (in the **Plexora** menu on macOS) checks for a newer release.
