```python
project_from_spec(spec, node=None) -> str
```

The same as [`create_project(**spec)`](/docs/python-api/projects/create-project) -- this is what the CLI's `--from
file.json` and `create_dataset(projects=[...])` both call, so a spec
document means one thing everywhere it is read.

## Parameters

<ParamTable>

<Param name={"spec"} type={"dict"} required>

A project spec: any of [`PROJECT_SPEC_KEYS`](/docs/python-api/projects/project-spec-keys), with `image`
required.

</Param>

<Param name={"node"} type={"str"} default={"None"}>

The data node any path in `spec` is on, unless
the spec says otherwise for itself.

</Param>

</ParamTable>
