[`plan_dataset`](/docs/python-api/datasets/plan-dataset), then [`create_dataset`](/docs/python-api/datasets/create-dataset) with the projects it planned: every
image becomes a project, with the mask, table and channel names matched
to it. Files are registered where they are, not copied. Files the plan
could not place (`unassigned`) are left out; pass `overrides` to place
them, or use [`plan_dataset`](/docs/python-api/datasets/plan-dataset) first to see them. On a files-only server
(`sftp://`) images and masks stream from where they are and each cell
table is copied to this computer, since a CSV cannot be streamed.

## When to use

Use this for a cohort folder whose files are named consistently --
`registration/`, `segmentation/`, `quantification/`, or a folder per
sample. Use [`create_dataset`](/docs/python-api/datasets/create-dataset) with explicit specs when the folder
layout does not say which file is which.
