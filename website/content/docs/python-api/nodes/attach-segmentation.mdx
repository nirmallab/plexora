Whether the node's mask is a filled pyramid or an outline pyramid is read
off the node's own description rather than assumed: both serve tiles
happily, and drawing one as the other paints a wrong picture without
raising any error.

## Parameters

<ParamTable>

<Param name={"project"} type={"str | Project"} required>

The project to update, by name or object.

</Param>

<Param name={"node"} type={"str"} required>

The registered node serving the file.

</Param>

<Param name={"resource_id"} type={"str"} required>

The segmentation resource's id on that node (see
[`plexora.node_resources`](/docs/python-api/nodes/node-resources)).

</Param>

<Param name={"reload"} type={"bool"} default={"True"}>

Reload the project in this process after
saving. Defaults to `True`.

</Param>

</ParamTable>

## Returns

<Returns type={"Project"}>

The project, saved with the mask pointed at the node and
(unless `reload=False`) reloaded.

</Returns>

## Raises

<Raises>

<Raise type={"KeyError"}>

If `project` names an unknown project, or `node` names an
unregistered node.

</Raise>

</Raises>
