Writes directly to Plexora's project registry. The project opens
immediately; a mask or a cell table can be attached to it later, by
re-registering the same `name` with [`plexora.register_datasource`](/docs/python-api/datasources/register-datasource) or
[`plexora.register_anndata_datasource`](/docs/python-api/datasources/register-anndata-datasource).

## When to use

A quick first look at a slide before anything else about it is
known. [`plexora.create_project(image)`](/docs/python-api/projects/create-project) does the same job and is
the newer entry point, letting [`plexora.configure_project`](/docs/python-api/projects/configure-project) fill in
a table or mask afterwards; use `register_image_datasource` for a
script that only ever has the image.

## Parameters

<ParamTable>

<Param name={"name"} type={"str"} required>

The project's name.

</Param>

<Param name={"image"} type={"str | Path"} required>

The whole-slide image -- OME-TIFF/TIFF, DICOM,
or a Zarr store. A web address is read in place.

</Param>

<Param name={"channel_names"} type={"list[str]"} default={"None"}>

A name for each image
channel, in channel order. Derived from the image's own
metadata (or generic `"Channel N"` names) when not given.

</Param>

<Param name={"copy"} type={"bool"} default={"False"}>

Copy `image` into the project's own folder
instead of reading it where it is. Defaults to False.

</Param>

<Param name={"data_dir"} type={"str | Path"} default={"None"}>

The data root to register the
project under. Defaults to Plexora's configured data directory.

</Param>

<Param name={"image_type"} type={"str"} default={"None"}>

`"brightfield"` or `"fluorescence"`, to
override how the image is read. Defaults to None, which
decides from the file.

</Param>

<Param name={"pyramidize"} type={"bool"} default={"None"}>

What to do with a large multiplex
TIFF that has no reduced-resolution levels. None (the default)
and True write a pyramidized copy once, as
`<name>.pyramid.ome.tiff` beside the original (or in the
project's folder when that one is not writable), and open the
copy; the original is never changed. False opens the original
as it is.

</Param>

</ParamTable>

<Returns type={"dict"}>
