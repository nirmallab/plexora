Plexora decides what a file is from its contents first and its extension second, so the tables below list what each extension is tried as. A file that does not match what its extension suggests is still identified correctly or refused with a message saying why.

## Images

| Extension | Read as | Notes |
|---|---|---|
| `.bif` | Brightfield whole-slide image | Roche Ventana whole-slide image, read as brightfield. Local or at a web address. |
| `.dcm` | Image | DICOM whole-slide image (a folder of .dcm files), read with wsidicom. Local or at a web address (`pip install "plexora[remote]"`). |
| `.jpeg` | Image | Single-plane RGB or grayscale image. Local or at a web address. |
| `.jpg` | Image | Single-plane RGB or grayscale image. Local or at a web address. |
| `.mrxs` | Brightfield whole-slide image | 3DHISTECH whole-slide image. Needs the `wsi` extra (`pip install "plexora[wsi]"`). Local only. |
| `.ndpi` | Brightfield whole-slide image | Hamamatsu whole-slide image, read as brightfield. Local or at a web address. |
| `.png` | Image | Single-plane RGB or grayscale image. Local or at a web address. |
| `.qptiff` | Image | Akoya PhenoImager (Vectra/Polaris) multiplex image. Local or at a web address. |
| `.scn` | Brightfield whole-slide image | Leica whole-slide image, read as brightfield. Local or at a web address. |
| `.svs` | Brightfield whole-slide image | Aperio whole-slide image, read as brightfield. Local or at a web address. |
| `.svslide` | Brightfield whole-slide image | Sakura whole-slide image. Needs the `wsi` extra. Local only. |
| `.tif` | Image | TIFF or OME-TIFF image, or a label mask. An image may also be at a web address. |
| `.tiff` | Image | TIFF or OME-TIFF image, or a label mask. An image may also be at a web address. |

## Cell tables

| Extension | Read as | Notes |
|---|---|---|
| `.csv` | Delimited table | Comma-separated cell table. |
| `.h5ad` | AnnData | AnnData. Coordinates from `obsm["spatial"]` or two `obs` columns. |
| `.parquet` | Parquet table | Parquet cell table. |
| `.tsv` | Delimited table | Tab-separated cell table. |
| `.txt` | Delimited table | Tab- or comma-separated cell table. |

## Folders and run outputs

| Folder or store | What Plexora reads | Guide |
|---|---|---|
| OME-Zarr (`.zarr` folder) | A multiscale image, local or at an `https://`, `s3://`, `gs://` or `az://` address. | [Multiplexed imaging](/docs/modalities/multiplexed-imaging) |
| SpatialData (`.zarr` folder with `tables/`) | Images, labels, points and a cell table from one store. | [SpatialData](/docs/modalities/spatialdata) |
| Xenium output folder | Morphology image, cell and nucleus boundaries, cells, transcripts. | [Xenium](/docs/modalities/xenium) |
| Visium output folder (`outs/`) | Tissue image, spot positions and the spot-by-gene matrix. | [Visium](/docs/modalities/visium) |
| Visium HD output folder (`outs/`) | Tissue image and the 2, 8 and 16 µm bin matrices. | [Visium HD](/docs/modalities/visium-hd) |
| DICOM whole-slide folder | A pyramidal brightfield or multiplex slide stored as DICOM instances, local or in a bucket (`s3://`, `gs://`, `az://`). | [Brightfield whole-slide images](/docs/modalities/brightfield-wsi) |

## Not supported

These formats are recognised by name but not imported. See [Formats that are not supported yet](/docs/modalities/not-supported) for workarounds.

| Format | Status |
|---|---|
| NanoString CosMx output | Not supported. Export a cell table and image and import them as files. |
| Vizgen MERSCOPE output | Not supported. Export a cell table and image and import them as files. |
| Feather tables | Not supported. Convert to Parquet or CSV. |
| GeoJSON shapes | Recorded on import but not drawn. |
| Xenium cell-feature matrix | Recorded on import but not read; the cell table supplies per-cell values. |
