## Usage

```bash
plexora project import [-h] [--into LOCATION] [--keep-both | --replace] [--name NAME] file
```

<Param name={"file"} required />

## Options

<ParamTable>

<Param name={"--into LOCATION"}>

The location to put them in, by its id (Settings > Data lists them); default: where new projects go.

</Param>

<Param name={"--keep-both"}>

A project already here is imported beside it, under the next free name.

</Param>

<Param name={"--replace"}>

A project already here is replaced; its state is kept in .replaced/.

</Param>

<Param name={"--name NAME"}>

A name for it, if not the one it has (a file of one project).

</Param>

</ParamTable>

Only one of `--keep-both`, `--replace` may be given.
