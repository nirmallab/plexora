<Param name={"--dataset DATASET"}>

Every project of this dataset (by name or id), with the dataset itself.

</Param>

<Param name={"--include PARTS"}>

Also carry, comma-separated: images (the images, masks and tables the projects read), derived (files Plexora made that save rebuilding them), approximate (with images: each 16-bit fluorescence image about 85% smaller, every pixel within its own noise; masks and tables stay exact). Tables, captures and figures always go.

</Param>
