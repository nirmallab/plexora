Plexora installs one command, `plexora`. On its own it starts the viewer
and opens it in your browser. The subcommands below say where data lives,
start Plexora on another machine, serve files to a viewer elsewhere, and
register projects and datasets without opening the viewer.

Every command accepts `--help`. Options shown here are generated from the
command's own definition, so they match the installed version.

| Command | What it does |
|---|---|
| [`plexora`](/docs/reference/cli/plexora) | Start the Plexora local image viewer server. |
| [`plexora where`](/docs/reference/cli/where) | Print the resolved data directory and how it was chosen. |
| [`plexora config`](/docs/reference/cli/config) | Show or change where Plexora keeps its data. |
| [`plexora config show`](/docs/reference/cli/config/show) | Print the current settings file. |
| [`plexora config set`](/docs/reference/cli/config/set) | Change a setting. |
| [`plexora connect`](/docs/reference/cli/connect) | Start Plexora on a remote host, tunnel to it, and open a browser here. Run this on your OWN computer, not on the remote host. |
| [`plexora node`](/docs/reference/cli/node) | Serve data files to a Plexora viewer running elsewhere. A node has no viewer and no project registry of its own -- it hands out bytes from the files it is pointed at. |
| [`plexora node serve`](/docs/reference/cli/node/serve) | Serve one or more files to a Plexora viewer. |
| [`plexora node connect`](/docs/reference/cli/node/connect) | Start a data node on another machine and register it here. |
| [`plexora node prepare`](/docs/reference/cli/node/prepare) | Convert a label mask into something a node can serve. |
| [`plexora dataset`](/docs/reference/cli/dataset) | Group projects into datasets -- a cohort, a TMA series, one imaging run. |
| [`plexora dataset create`](/docs/reference/cli/dataset/create) | Make a dataset, registering its images if needed. |
| [`plexora dataset list`](/docs/reference/cli/dataset/list) | Every dataset on this machine. |
| [`plexora dataset show`](/docs/reference/cli/dataset/show) | One dataset and what is in it. |
| [`plexora dataset add`](/docs/reference/cli/dataset/add) | Put existing projects in a dataset. |
| [`plexora dataset remove`](/docs/reference/cli/dataset/remove) | Take projects out of a dataset. They are NOT deleted. |
| [`plexora dataset rename`](/docs/reference/cli/dataset/rename) | Rename a dataset. |
| [`plexora dataset delete`](/docs/reference/cli/dataset/delete) | Delete a dataset. The projects in it stay. |
| [`plexora project`](/docs/reference/cli/project) | Register a project from an image, and fill in what it needs as you find out. |
| [`plexora project create`](/docs/reference/cli/project/create) | Register a project from an image, files, or a run folder. |
| [`plexora project show`](/docs/reference/cli/project/show) | What a project has, and what is still open. |
| [`plexora project set`](/docs/reference/cli/project/set) | Answer a question about a registered project. |
