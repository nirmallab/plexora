## Methods

### label_volume

```python
label_volume(t: int = 0)
```

The mask as a 3-D label volume -- one id per cell across planes -- at frame `t` of a time series, or None for a 2-D mask (one segmentation drawn on every plane).

Its `read(level, z0, z1, rows, cols)` gives `(Z, H, W)` label ids;
`plane(z)` one plane's 2-D pyramid; `depth`, `height`, `width`,
`frames`. A mask held on a data node comes back as a
`providers.node.NodeLabelVolume`, the same face read over the wire.

<ParamTable>

<Param name={"t"} type={"int"} default={"0"}>

The frame of a time series; 0 for a single z-stack.

</Param>

</ParamTable>

<Returns type={"LabelVolume | NodeLabelVolume | None"}>

None for a 2-D mask or a
project without one.

</Returns>

### read_region

```python
read_region(level, box, max_pixels=0)
```

Read cell-label pixels for a rectangle of the mask.

Reads wherever the mask physically is -- local file or data node --
without the caller having to choose.

<ParamTable>

<Param name={"level"} type={"int"} required>

The pyramid level to read at, 0 being full resolution.

</Param>

<Param name={"box"} type={"tuple"} required>

`(x0, y0, x1, y1)` in that level's own pixel
coordinates.

</Param>

<Param name={"max_pixels"} type={"int"} default={"0"}>

Downsample so the returned array has
at most this many pixels. 0 (the default) means no limit.

</Param>

</ParamTable>

<Returns>

An array of uint32 cell-label ids, one per pixel of the box that
actually existed; 0 where the box runs off the mask.

</Returns>

### centroid_tiles

```python
centroid_tiles(level, tiles, gates=None, max_points=None)
```

Cell centroids for a set of tiles, optionally gated.

<ParamTable>

<Param name={"level"} type={"int"} required>

The centroid cache's pyramid level.

</Param>

<Param name={"tiles"} type={"list[dict]"} required>

Which tiles to read, each `{"x": ..., "y": ...}`
in that level's tile grid, as named by `centroid_manifest()`.

</Param>

<Param name={"gates"} type={"dict"} default={"None"}>

`{column: (low, high)}` ranges; only cells
whose rows satisfy every range are returned. None (the
default) returns every cell in the requested tiles.

</Param>

<Param name={"max_points"} type={"int"} default={"None"}>

Thin each tile down to at most this
many points. None (the default) returns every matching point.

</Param>

</ParamTable>

<Returns>

A numpy structured array with `id`, `x` and `y` fields, one row
per centroid.

</Returns>
