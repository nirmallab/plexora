Everything the Open Project page, the Samples page and the viewer can do is
also a Python call. Use it to register a cohort in a loop instead of one
upload at a time, answer a project's open questions from a script, open the
viewer from a notebook, or read files that live on another machine.

```python
import plexora
```

Every function below is then `plexora.<name>` — there is nothing else to
import, and no server to start first: registering a project just writes to
the same project registry the app reads.
