    Usage data

    Plexora can send anonymous usage counts — which features are used, how long tiles take to draw, which kinds of errors occur — so we know what to improve. It never sends file names, project names, marker or gene names, cell data, coordinates, usernames, machine names or anything typed into a tool. Everything is queued on this machine first, and nothing in Plexora waits for it or depends on it.
